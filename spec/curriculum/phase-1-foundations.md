# Phase 1 · Python Foundations

**Goal:** write correct, readable Python programs: values, control flow, data structures, functions, text, files, errors and modules.
**Modules:** M01–M06 · 40 lessons · ~50.5 h · **Portfolio project P1:** CLI Expense Tracker (`spec/09`) · **Phase exam `p1-exam`:** 30 questions + 3 coding tasks, 90 minutes.

**Phase teaching notes**
* **M01** exercises are whole programs graded by **output tests**: the pytest file runs the learner's script with `run_program(path, stdin=...)` and compares what it prints (`spec/05` §5). Give each one at least 3 input cases so hard-coding the answer fails.
* **M02-L01 introduces the "function shell":** the starter already has `def name(params):` and `return`, and the learner fills in the body ("a named recipe; you'll write your own in M04"). From then on, most exercises are functions graded by `assert` tests.
* Signatures below include type hints for clarity. **Don't put type hints in starters until M04-L04** teaches them; add them from then on.
* Beginners: one new idea per section, no clever one-liners in worked examples, and every error message explained.
