Python for AI: Zero to Job-Ready

From your first program to machine learning, deep learning and LLM applications. Every lesson teaches the essentials first and then documents the whole topic, so the course stays useful as a reference long after you finish it.

How the course works

  1. Set up your computer (30 minutes, once): install Python, an editor and the course tools with the setup guide.
  2. Read a lesson with the essentials marked, and run every example yourself: each one shows the command to type.
  3. Do the exercises in your editor and check them with pytest. A passing run prints a completion code that records your progress here.
  4. Take the quiz at the end of the lesson. It runs in the page and explains every answer.

How the lessons work

Everything in a lesson is marked by how much you need it:

  • ●Essential what you need to continue the course;
  • ◆Extra info deeper understanding, safe to skip on a first pass;
  • ▲Advanced edge cases and internals, for later and for reference.

Use Show in the header, or the reading settings (Aa), to choose how much you see: Essentials turns any lesson, its reference tables included, into a cheat sheet. Coloured boxes mark tips, common mistakes, version notes, interview questions and what the topic looks like on the job.

Python never runs inside these pages. Each example shows the output that real Python printed when the course was built, with the command that runs it; copy or download it and run it yourself. That is how professionals work, and it means the course works offline.

Looking for one function? Press / to search, or open the API index. Press ? for every keyboard shortcut.
