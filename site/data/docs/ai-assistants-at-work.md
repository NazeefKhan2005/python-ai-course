# Using AI assistants at work

AI assistants can help you write, code and analyse faster. These rules keep that safe.

## Approved tools

* **The company AI assistant**, available to everyone through single sign-on. Our contract says the provider does not train on our data.
* **The coding assistant** in the company code editor, for engineers.

Other AI tools are not approved for company data. You may use them for public information only, such as learning a new topic.

## Data in prompts

* Never put **Restricted** data into any AI tool, approved or not. This includes payment details, home addresses, courier location traces and identity documents.
* Put **Confidential** data only into approved tools, and only what the task needs.
* Remove names and contact details from customer messages before you ask an assistant to summarise them.

## You are responsible for the output

* Check facts, numbers and references yourself. AI assistants can be confidently wrong.
* Review AI-written code like a colleague's code: read it, test it, and understand it before you merge it.
* A person must review every customer-facing message written with AI before it is sent.
* Never use AI tools to make decisions about people, such as hiring, performance ratings or courier deactivation.

## Prompt injection

Text that comes from outside the company (customer messages, restaurant menus, web pages, even pages in our own wiki that anyone can edit) can contain hidden instructions aimed at AI tools. Treat such text as data, never as instructions. If an assistant suddenly behaves strangely, for example by approving something or asking for a password, stop and report it.

## Questions and problems

Write to ai-help@colibri.example. Report data leaks through AI tools as a data incident (see Customer data and privacy).
